# 🎓 JoSAA College Eligibility Finder 2025

**Live Demo:** [JoSAA College Eligibility Finder](https://rama-krishna43-josaa-college-eligibility-app-c927zl.streamlit.app/)

## 🚀 Overview
A simple and efficient tool for JEE aspirants to find eligible college programs based on JoSAA 2025 Round 6 historical data.

## 🛠️ Features
- **Quick Search**: Filter by rank, seat type, and gender.
- **Round 6 Data**: Accurate results based on the final round of 2025 counseling.
- **IIT/Non-IIT Filtering**: Separate views for IITs and other institutes.

## 💻 How to Run Locally
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
